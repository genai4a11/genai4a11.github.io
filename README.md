# 🧠 GenAI Mindmap

An interactive knowledge map of the Generative AI landscape — covering prompting, RAG, agents, fine-tuning, infrastructure, evaluation, safety, and applications.

**Live site:** [genai4a11.github.io](https://genai4a11.github.io)

---

## What's inside

- **300+ nodes** across 5 clusters: Foundations, Building, Applications, Frontier Research, and Production
- **Rich content** on every major node — use cases, diagrams, code examples, and tips
- **Real-time search** across all nodes
- **Role-based views** *(coming soon)* — PM, business, and engineering perspectives

---

## How to use

- **Click** a node to open its detail panel
- **Click the ▸ chip** on a node to expand its subtopics
- **Search** using the bar at the top
- **Use the Clusters panel** (bottom-left) to navigate by domain
