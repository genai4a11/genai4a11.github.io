Instructor

A Python library that makes it trivial to get structured, validated outputs from LLMs using Pydantic models — the simplest path from LLM text to typed Python objects.

Validation
Pydantic v2
Retry logic
built-in
Backends
OpenAI/Anthropic/Gemini/Ollama

SECTION 01
('What Is Instructor?', 'Instructor wraps LLM clients (OpenAI, Anthropic, Gemini, Cohere, Ollama) and patches them to accept a response_model parameter. You pass a Pydantic model as the expected return type; Instructor prompts the LLM to return JSON matching that schema, validates the output, and automatically retries on validation failures. The result: every LLM call returns a typed Python object.')
SECTION 02
('Basic Usage', 'from pydantic import BaseModel\nimport instructor\nfrom openai import OpenAI\n\nclient = instructor.from_openai(OpenAI())\n\nclass UserInfo(BaseModel):\n name: str\n age: int\n email: str\n\nuser = client.chat.completions.create(\n model="gpt-4o-mini",\n response_model=UserInfo,\n messages=[{"role": "user", "content": "Extract: John Smith, 34 years old, john@example.com"}],\n)\nprint(user.name) # "John Smith"\nprint(user.age) # 34\nprint(user.email) # "john@example.com"\nprint(type(user)) # ')
SECTION 03
('Validation & Retries', 'Pydantic validators run on the extracted output. If validation fails, "\n "Instructor retries with the error message appended to the prompt — "\n "the LLM sees its mistake and corrects it.\n\nfrom pydantic import BaseModel, field_validator\n\nclass ProductReview(BaseModel):\n sentiment: str\n score: int\n summary: str\n\n @field_validator("score")\n def score_range(cls, v):\n if not 1 <= v <= 5:\n raise ValueError("Score must be between 1 and 5")\n return v\n\n @field_validator("sentiment")\n def sentiment_values(cls, v):\n if v not in ("positive", "negative", "neutral"):\n raise ValueError("Must be positive, negative, or neutral")\n return v\n\nreview = client.chat.completions.create(\n model="gpt-4o-mini",\n response_model=ProductReview,\n max_retries=3, # retry up to 3 times on validation error\n messages=[{"role": "user", "content": "Review: Great product, works perfectly! 5 stars."}],\n)')
SECTION 04
('Nested Models', 'Instructor handles arbitrarily nested Pydantic models — "\n "LLMs reliably produce complex structured outputs.\n\nfrom typing import Optional\nfrom pydantic import BaseModel\n\nclass Address(BaseModel):\n street: str\n city: str\n country: str\n\nclass Company(BaseModel):\n name: str\n industry: str\n founded_year: Optional[int] = None\n headquarters: Address\n\ncompany = client.chat.completions.create(\n model="gpt-4o",\n response_model=Company,\n messages=[{"role": "user", "content": "Extract company info: OpenAI, founded 2015, San Francisco, AI research"}],\n)\nprint(company.headquarters.city) # "San Francisco"')

('Streaming Structured Output', "Instructor supports streaming partial objects as they're generated — useful for progressive rendering in UIs. Use instructor.Partial[YourModel] as the response_model to receive partial objects as each field completes.")
SECTION 06
('When to Use Instructor', "Use when you need: typed LLM outputs in Python, zero-boilerplate JSON extraction, automatic validation and retries, or complex nested data structures from unstructured text. It's the fastest way to go from 'I want structured data from LLM' to working code.")
