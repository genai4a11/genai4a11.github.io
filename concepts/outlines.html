Outlines

A Python library for constrained text generation — enforcing JSON schemas, regex patterns, and grammars at the token level for local models, guaranteeing 100% format compliance.

Compliance
100%
Backends
HuggingFace/vLLM/llama.cpp/mlx
Method
token-level FSM masking

SECTION 01
('What Is Outlines?', 'Outlines provides constrained generation for locally-run models. Unlike prompt-based approaches (which have ~90% compliance), Outlines applies a finite state machine (FSM) mask at the logit level: only tokens that could produce a valid output are sampled. The result is 100% format compliance with no retries. Works with HuggingFace Transformers, vLLM, llama.cpp, and Apple MLX.')
SECTION 02
('JSON Schema Generation', 'from pydantic import BaseModel\nfrom typing import Literal\nimport outlines\n\nmodel = outlines.models.transformers("mistralai/Mistral-7B-Instruct-v0.2")\n\nclass Sentiment(BaseModel):\n label: Literal["positive", "negative", "neutral"]\n confidence: float\n reasoning: str\n\ngenerator = outlines.generate.json(model, Sentiment)\n\nresult = generator("Classify: The product exceeded my expectations in every way!")\nprint(result.label) # "positive"\nprint(result.confidence) # 0.95 (or similar)\nprint(type(result)) # ')
SECTION 03
('Regex & Choice', 'For simple structured outputs, regex and choice generators are faster than full JSON schemas.\n\nimport outlines\n\nmodel = outlines.models.transformers("microsoft/phi-2")\n\n# Force a choice from a fixed set\nclassifier = outlines.generate.choice(model, ["spam", "not_spam"])\nlabel = classifier("Email: Congratulations! You won $1000000. Click here!")\nprint(label) # "spam"\n\n# Force a regex pattern — e.g. ISO date\ndate_gen = outlines.generate.regex(model, r"\\d{4}-\\d{2}-\\d{2}")\ndate = date_gen("When did World War II end? ")\nprint(date) # "1945-09-02"')
SECTION 04
('Custom Grammars', "For complex structured outputs (SQL, code, custom DSLs), define a context-free grammar. Outlines supports EBNF grammars: any output matching the grammar is valid, any output that doesn't is impossible to generate. This is particularly powerful for code generation where syntactic correctness is required.")
SECTION 05
('vLLM Integration', "Outlines integrates natively with vLLM's guided decoding feature. Pass a json_schema or regex to vLLM's SamplingParams and constrained generation runs at full GPU throughput — no latency overhead beyond the FSM computation. This makes Outlines the go-to solution for high-throughput structured generation at scale.")
SECTION 06
('Outlines vs Instructor', "Instructor works with API models (OpenAI, Anthropic) via prompt engineering + retry loops. Outlines works with local models via true token-level constraints. Use Instructor for API-based workflows where occasional retries are acceptable. Use Outlines when you need guaranteed compliance, run local models, or can't afford retries.")
