SECTION 01

Beyond JSON mode: token-level guarantees

JSON mode from hosted providers (OpenAI, Anthropic) gives you high-reliability JSON — but it's implemented via training and retries, not mathematical guarantees. For local models (Llama, Mistral, Phi) there's no "JSON mode" switch at all.

Outlines solves this differently: it compiles your constraint (a regex, a JSON schema, a grammar) into a Finite State Machine, then at each decoding step it calculates which tokens can legally extend the current output prefix and masks all others to probability 0. The result is a hard guarantee: it is impossible for the model to produce output that violates the constraint.

SECTION 02

How Outlines works

The key insight: a regex or JSON schema defines a set of valid strings. This set can be represented as a Finite State Machine (FSM). At decoding step t, the FSM is in some state s. The set of tokens that keep the FSM in a valid state is the allowed token set. All other tokens get logit = -∞ before softmax, making them impossible.

This happens synchronously during generation — there's no retry loop, no post-processing. The model simply cannot stray from the valid set.

The FSM compilation step is expensive (seconds) but happens once per unique constraint. Outlines caches it aggressively.

Installation and backends

import outlines

# HuggingFace Transformers backend
model = outlines.models.transformers(
    "microsoft/Phi-3.5-mini-instruct",
    device="cuda"
)

# vLLM backend (for production throughput)
model = outlines.models.vllm("mistralai/Mistral-7B-Instruct-v0.3")

Outlines primarily targets local model inference. For hosted APIs (OpenAI, Anthropic) use their native JSON mode or Instructor instead — those providers don't expose logits.

SECTION 04

Regex constraints

import outlines

model = outlines.models.transformers("microsoft/Phi-3.5-mini-instruct")

# Force output to match a date pattern YYYY-MM-DD
generator = outlines.generate.regex(
    model,
    r"(19|20)\d\d-(0[1-9]|1[0-2])-(0[1-9]|[12]\d|3[01])"
)

date = generator("When was the first iPhone released? Date: ")
print(date)  # 2007-01-09  — guaranteed to match the regex

# US phone number
phone_gen = outlines.generate.regex(
    model,
    r"\(\d{3}\) \d{3}-\d{4}"
)
phone = phone_gen("Customer support number: ")
print(phone)  # (800) 555-0199

# Float with 2 decimal places
price_gen = outlines.generate.regex(model, r"\d+\.\d{2}")
price = price_gen("The price is $")
print(price)  # 24.99
SECTION 05

JSON schema enforcement

from pydantic import BaseModel
from typing import Literal
import outlines

model = outlines.models.transformers("mistralai/Mistral-7B-Instruct-v0.3")

class MovieReview(BaseModel):
    title: str
    year: int
    rating: float           # 0.0 - 10.0
    genre: Literal["action", "comedy", "drama", "sci-fi", "horror"]
    summary: str

generator = outlines.generate.json(model, MovieReview)

review = generator(
    "Write a review for Inception (2010), a mind-bending sci-fi thriller. "
    "Christopher Nolan's masterpiece explores dreams within dreams."
)

# review is a MovieReview Pydantic object — guaranteed valid
print(review.rating)  # 9.2 (type: float)
print(review.genre)   # sci-fi (guaranteed to be one of the 5 options)

Outlines converts the Pydantic model to JSON Schema, compiles an FSM from the schema, and guides decoding. Every field is guaranteed to have the correct type and every enum value is guaranteed to be in the allowed set.

SECTION 06

Choice constraints

import outlines

model = outlines.models.transformers("microsoft/Phi-3.5-mini-instruct")

# Hard classification — output MUST be one of these exact strings
classifier = outlines.generate.choice(
    model,
    ["positive", "negative", "neutral"]
)

labels = [
    classifier(f"Classify the sentiment of: '{text}'")
    for text in ["Great product!", "Total waste of money", "It's okay"]
]
print(labels)  # ['positive', 'negative', 'neutral']

# Binary yes/no
yesno = outlines.generate.choice(model, ["yes", "no"])
answer = yesno("Is Paris the capital of France? Answer yes or no: ")
print(answer)  # yes

Choice constraints are the simplest and fastest Outlines constraint — the FSM has exactly N terminal states, one per choice.

SECTION 07

Context-free grammars

For structured output that goes beyond what regex can express (e.g., nested arithmetic, SQL, simple programming languages) Outlines supports EBNF grammars:

import outlines

model = outlines.models.transformers("mistralai/Mistral-7B-Instruct-v0.3")

# Simple arithmetic expression grammar
arithmetic_grammar = '''
    expression: term ((PLUS | MINUS) term)*
    term: factor ((TIMES | DIVIDE) factor)*
    factor: NUMBER | LPAREN expression RPAREN
    NUMBER: /[0-9]+(\.[0-9]+)?/
    PLUS: "+"
    MINUS: "-"
    TIMES: "*"
    DIVIDE: "/"
    LPAREN: "("
    RPAREN: ")"
    %ignore /\s+/
'''

generator = outlines.generate.cfg(model, arithmetic_grammar)
expr = generator("Write an arithmetic expression for the area of a 5×3 rectangle: ")
print(expr)  # 5 * 3   — guaranteed to be valid arithmetic

CFG-guided generation is powerful but the FSM compilation is significantly more expensive than regex or JSON schema. Reserve it for complex structured outputs.
