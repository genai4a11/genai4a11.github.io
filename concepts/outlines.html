SECTION 01

What Is Outlines?

Outlines provides constrained generation for locally-run models. Unlike prompt-based approaches (which have ~90% compliance), Outlines applies a finite state machine (FSM) mask at the logit level: only tokens that could produce a valid output are sampled. The result is 100% format compliance with no retries. Works with HuggingFace Transformers, vLLM, llama.cpp, and Apple MLX.

SECTION 02

JSON Schema Generation

from pydantic import BaseModel
from typing import Literal
import outlines
model = outlines.models.transformers("mistralai/Mistral-7B-Instruct-v0.2")
class Sentiment(BaseModel):
    label: Literal["positive", "negative", "neutral"]
    confidence: float
    reasoning: str
generator = outlines.generate.json(model, Sentiment)
result = generator("Classify: The product exceeded my expectations in every way!")
print(result.label)        # "positive"
print(result.confidence)   # 0.95 (or similar)
print(type(result))        # <class 'Sentiment'>
SECTION 03

Regex & Choice

For simple structured outputs, regex and choice generators are faster than full JSON schemas.

import outlines
model = outlines.models.transformers("microsoft/phi-2")
# Force a choice from a fixed set
classifier = outlines.generate.choice(model, ["spam", "not_spam"])
label = classifier("Email: Congratulations! You won $1000000. Click here!")
print(label)  # "spam"
# Force a regex pattern — e.g. ISO date
date_gen = outlines.generate.regex(model, r"\d{4}-\d{2}-\d{2}")
date = date_gen("When did World War II end? ")
print(date)  # "1945-09-02"
SECTION 04

Custom Grammars

For complex structured outputs (SQL, code, custom DSLs), define a context-free grammar. Outlines supports EBNF grammars: any output matching the grammar is valid, any output that doesn't is impossible to generate. This is particularly powerful for code generation where syntactic correctness is required.

SECTION 05

vLLM Integration

Outlines integrates natively with vLLM's guided decoding feature. Pass a json_schema or regex to vLLM's SamplingParams and constrained generation runs at full GPU throughput — no latency overhead beyond the FSM computation. This makes Outlines the go-to solution for high-throughput structured generation at scale.

SECTION 06

Outlines vs Instructor

Instructor works with API models (OpenAI, Anthropic) via prompt engineering + retry loops. Outlines works with local models via true token-level constraints. Use Instructor for API-based workflows where occasional retries are acceptable. Use Outlines when you need guaranteed compliance, run local models, or can't afford retries.
