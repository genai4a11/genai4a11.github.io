SECTION 01
('What Is Modal?', 'Modal is a serverless compute platform designed for ML/AI workloads. You write Python functions decorated with @app.function(); Modal handles containerisation, scheduling, autoscaling, and GPU provisioning. Unlike AWS Lambda, Modal supports GPU instances, long-running jobs, and arbitrary Python dependencies. Sub-second cold starts for CPU; 1–3 second cold starts for GPU instances with pre-cached container images.')
SECTION 02
('Functions & Containers', 'Define a Modal app with a container image and annotated functions.\n\nimport modal\n\napp = modal.App("llm-inference")\n\nimage = modal.Image.debian_slim().pip_install(\n "torch", "transformers", "accelerate"\n)\n\n@app.function(gpu="T4", image=image, timeout=300)\ndef generate_text(prompt: str) -> str:\n from transformers import pipeline\n pipe = pipeline("text-generation", model="gpt2", device=0)\n result = pipe(prompt, max_new_tokens=100)[0]["generated_text"]\n return result\n\n# Run locally via Modal\nwith app.run():\n result = generate_text.remote("The future of AI is")\n print(result)')
SECTION 03
('Running LLM Inference', 'For production LLM serving, use modal serve to keep a warm instance running. "\n "vLLM on Modal is a common pattern for cheap, scalable LLM APIs.\n\n@app.cls(gpu="A10G", image=image, concurrency_limit=10)\nclass LLMServer:\n @modal.enter()\n def load_model(self):\n from vllm import LLM, SamplingParams\n self.llm = LLM(model="mistralai/Mistral-7B-Instruct-v0.2")\n\n @modal.method()\n def generate(self, prompt: str) -> str:\n params = SamplingParams(temperature=0.7, max_tokens=512)\n outputs = self.llm.generate([prompt], params)\n return outputs[0].outputs[0].text\n\n@app.function()\n@modal.web_endpoint(method="POST")\ndef inference_endpoint(request: dict) -> dict:\n server = LLMServer()\n return {"response": server.generate.remote(request["prompt"])}')
SECTION 04
('Scheduled Jobs', "Run batch jobs on a schedule with @app.function(schedule=...). Modal.Period(hours=24) runs daily; modal.Cron('0 2 * * *') runs at 2 AM. Ideal for: nightly data processing, scheduled eval runs, dataset refresh pipelines, and periodic report generation.")
SECTION 05
('Secrets & Storage', "Store API keys as Modal Secrets: modal.Secret.from_name('openai-secret'). Secrets are injected as environment variables into function containers. For persistent storage, use modal.Volume (NFS-like) or modal.CloudBucketMount (S3/GCS). modal.Volume persists across function calls and is mounted at a specified path.")
SECTION 06
('Comparison to Lambda/GCP Functions', "AWS Lambda: CPU only, 15-min timeout, 10GB memory. Good for lightweight APIs. Modal: GPU support, 24-hour timeout, arbitrary memory, Python-first. Good for AI workloads. GCP Cloud Run: container-based, GPU support (beta), scales to zero. Modal's key advantage: zero-config GPU provisioning and Python-native infrastructure definition that feels like local code.")
