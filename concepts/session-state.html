SECTION 01

Types of Session State

Conversation state: the message history (role, content, timestamp) for the current session. Agent state: intermediate results, tool call outputs, plan steps, and loop counters for agentic workflows. User state: long-term preferences, past interactions, and personalisation data. Each type has different durability, size, and access-pattern requirements.

SECTION 02

In-Memory vs Persistent

In-memory (Redis): sub-millisecond access, session TTL eviction, ideal for active conversations. Persistent (Postgres/DynamoDB): survives restarts, queryable, audit trail. Pattern: store active sessions in Redis with a 30-minute TTL; flush to Postgres on session end or at 5-minute checkpoints. Read from Redis if exists, else load from Postgres.

SECTION 03

Context Window Management

Conversation history grows unbounded; fit it in the model's context window with a sliding strategy. " "Options: (1) last-N turns only — simple but loses early context. " "(2) summarise older turns — preserves semantics, costs extra tokens. " "(3) retrieve relevant past turns — ideal but adds retrieval latency.

def trim_history(messages: list[dict], max_tokens: int = 8000) -> list[dict]:
    import tiktoken
    enc = tiktoken.get_encoding("cl100k_base")
    total = 0
    trimmed = []
    # Always keep system message
    system = [m for m in messages if m["role"] == "system"]
    rest = [m for m in messages if m["role"] != "system"]
    for m in reversed(rest):
        tokens = len(enc.encode(m["content"]))
        if total + tokens > max_tokens:
            break
        trimmed.insert(0, m)
        total += tokens
    return system + trimmed
SECTION 04

State Schema Design

Use a consistent schema for serialised session state to enable safe deserialization across versions.

from pydantic import BaseModel
from datetime import datetime
class Message(BaseModel):
    role: str
    content: str
    timestamp: datetime
    tokens: int = 0
class SessionState(BaseModel):
    session_id: str
    user_id: str
    created_at: datetime
    updated_at: datetime
    messages: list[Message] = []
    agent_scratchpad: dict = {}
    metadata: dict = {}
def add_message(self, role: str, content: str):
        self.messages.append(Message(role=role, content=content, timestamp=datetime.utcnow()))
        self.updated_at = datetime.utcnow()
SECTION 05

Multi-Turn Consistency

Guard against concurrent modifications: use optimistic locking (version counter) to detect if two requests modify the same session simultaneously. For agent loops, store a lock token in Redis with a short TTL (30 s) to prevent parallel agent runs from corrupting state.

SECTION 06

Cleanup & Expiry

Expire Redis sessions after 30 minutes of inactivity (EXPIRE command). Archive Postgres sessions older than 90 days to cold storage (S3). Delete agent scratchpad data immediately after the agent completes — it contains intermediate data that shouldn't persist. Run nightly cleanup jobs for orphaned sessions.
