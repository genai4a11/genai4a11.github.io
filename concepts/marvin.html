SECTION 01
('What Is Marvin?', "Marvin (by Prefect) wraps LLM calls in a clean, functional API. Instead of writing prompts, you call typed functions: marvin.classify(), marvin.extract(), marvin.transform(), marvin.generate(), marvin.cast(). The library handles prompt construction, output parsing, and type validation automatically. It's designed for developers who want LLM power without LLM boilerplate.")
SECTION 02
('Core Operations', 'classify: assign text to one of N categories. extract: pull structured entities from unstructured text. transform: rewrite text according to instructions. generate: produce a list of items matching criteria. cast: convert text to a Pydantic model or Python type. Each operation is a one-liner backed by a well-crafted system prompt.')
SECTION 03
('Classify & Extract', 'import marvin\nfrom typing import Literal\nfrom pydantic import BaseModel\n\n# Classify\nsentiment = marvin.classify(\n "The delivery was fast but the product broke within a week.",\n labels=["positive", "negative", "mixed"],\n)\nprint(sentiment) # "mixed"\n\n# Extract\nclass Location(BaseModel):\n city: str\n country: str\n\nlocations = marvin.extract(\n "I visited Paris, France and then Tokyo, Japan last summer.",\n target=Location,\n)\n# [Location(city=\'Paris\', country=\'France\'), Location(city=\'Tokyo\', country=\'Japan\')]')
SECTION 04
('Transform & Cast', '# Transform: rewrite text\nformal = marvin.transform(\n "hey can u send me that report asap lol",\n instructions="Rewrite as a formal business email",\n)\n\n# Cast: convert to a Python type\nfrom datetime import date\n\nevent_date = marvin.cast("the meeting is on March 15th 2025", target=date)\nprint(event_date) # datetime.date(2025, 3, 15)\n\n# Generate: create a list matching criteria\nnames = marvin.generate(\n n=5,\n target=str,\n instructions="Generate 5 plausible startup names for an AI productivity app",\n)')
SECTION 05
('Custom AI Functions', 'Marvin\'s @ai_fn decorator turns any Python function signature into an LLM call. "\n "The function body becomes the prompt context.\n\nimport marvin\n\n@marvin.fn\ndef get_rhyme(word: str) -> str:\n # Return a word that rhymes with the input\n pass\n\n@marvin.fn\ndef extract_action_items(meeting_notes: str) -> list[str]:\n # Extract all action items from the meeting notes as a list of strings\n pass\n\nprint(get_rhyme("cat")) # "hat"\nprint(extract_action_items("John will write the report. Sarah will call the client."))\n# ["John will write the report", "Sarah will call the client"')
SECTION 06
('When to Use Marvin', 'Marvin is ideal for: data enrichment pipelines (classify/extract at scale), quick LLM integration in existing Python code, and tasks where you want typed outputs without writing Pydantic models. For more complex pipelines with branching logic, use Haystack or LangChain instead.')
