SECTION 01

What Is Marvin?

Marvin (by Prefect) wraps LLM calls in a clean, functional API. Instead of writing prompts, you call typed functions: marvin.classify(), marvin.extract(), marvin.transform(), marvin.generate(), marvin.cast(). The library handles prompt construction, output parsing, and type validation automatically. It's designed for developers who want LLM power without LLM boilerplate.

SECTION 02

Core Operations

classify: assign text to one of N categories. extract: pull structured entities from unstructured text. transform: rewrite text according to instructions. generate: produce a list of items matching criteria. cast: convert text to a Pydantic model or Python type. Each operation is a one-liner backed by a well-crafted system prompt.

SECTION 03

Classify & Extract

import marvin
from typing import Literal
from pydantic import BaseModel
# Classify
sentiment = marvin.classify(
    "The delivery was fast but the product broke within a week.",
    labels=["positive", "negative", "mixed"],
)
print(sentiment)  # "mixed"
# Extract
class Location(BaseModel):
    city: str
    country: str
locations = marvin.extract(
    "I visited Paris, France and then Tokyo, Japan last summer.",
    target=Location,
)
# [Location(city='Paris', country='France'), Location(city='Tokyo', country='Japan')]
SECTION 04

Transform & Cast

# Transform: rewrite text
formal = marvin.transform(
    "hey can u send me that report asap lol",
    instructions="Rewrite as a formal business email",
)
# Cast: convert to a Python type
from datetime import date
event_date = marvin.cast("the meeting is on March 15th 2025", target=date)
print(event_date)  # datetime.date(2025, 3, 15)
# Generate: create a list matching criteria
names = marvin.generate(
    n=5,
    target=str,
    instructions="Generate 5 plausible startup names for an AI productivity app",
)

SECTION 06

When to Use Marvin

Marvin is ideal for: data enrichment pipelines (classify/extract at scale), quick LLM integration in existing Python code, and tasks where you want typed outputs without writing Pydantic models. For more complex pipelines with branching logic, use Haystack or LangChain instead.
