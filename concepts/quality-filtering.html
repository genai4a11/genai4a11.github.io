SECTION 01

Filter Taxonomy

Length filters: too short (< 50 tokens) or too long (> 4096 tokens). Language filters: keep only target language(s) (fastText langdetect). Perplexity filters: very high perplexity suggests garbled/random text. Repetition filters: high token n-gram repetition signals low-quality text. Safety filters: remove toxic, harmful, or NSFW content. Quality scorers: LLM or classifier that rates overall content quality.

SECTION 02

Heuristic Filters

Fast, cheap filters that catch obvious quality issues before expensive LLM scoring.

import re
from langdetect import detect
def heuristic_filter(text: str, target_lang: str = "en") -> tuple[bool, str]:
    # Length check
    words = text.split()
    if len(words) < 20:
        return False, "too_short"
    if len(words) > 4000:
        return False, "too_long"
    # Language check
    try:
        if detect(text[:500]) != target_lang:
            return False, "wrong_language"
    except Exception:
        return False, "lang_detect_failed"
    # Repetition check
    tokens = text.lower().split()
    unique_ratio = len(set(tokens)) / len(tokens)
    if unique_ratio < 0.2:
        return False, "high_repetition"
    # HTML artefacts
    if re.search(r"<[a-z]+[^>]*>", text):
        return False, "html_artefacts"
    return True, "ok"
SECTION 03

LLM Quality Scorer

Use a small LLM to score quality on a 1–5 scale. " "Train a regression model on LLM scores for 10× cheaper inference.

def score_quality(text: str) -> float:
    resp = client.chat.completions.create(
        model="gpt-4o-mini",
        messages=[{
            "role": "user",
            "content": (
                "Rate the quality of this text on a scale 1-5:\n"
                "1=very poor, 3=acceptable, 5=excellent\n\n"
                f"Text: {text[:500]}\n\nReply with just the number."
            )
        }],
        max_tokens=3,
        temperature=0,
    )
    try:
        return float(resp.choices[0].message.content.strip()) / 5.0
    except ValueError:
        return 0.5
SECTION 04

Safety & Toxicity Filters

Use dedicated classifiers for toxicity, hate speech, and harmful content: Perspective API (Google), Detoxify (open-source), or OpenAI moderation endpoint. Threshold: remove examples with toxicity score > 0.7. For fine-tuning data, also remove: instructions to deceive, instructions about illegal activities, and PII-containing examples.

SECTION 05

Deduplication at Scale

For millions of documents, exact hash dedup first (MD5 on normalised text), then MinHash LSH for near-duplicates (threshold 0.85). For web-scale data (100M+ documents), use SimHash or the dedup methodology from the Dolma/RedPajama pipeline (URL dedup → line dedup → document dedup). Dedup before quality scoring to avoid wasting LLM API calls on duplicates.

SECTION 06

Filter Pipeline Architecture

Stage 1 (cheap): language detect + length filter + hash dedup → drops 30–50%. Stage 2 (medium): MinHash dedup + heuristic quality filters → drops another 20–30%. Stage 3 (expensive): LLM quality scorer → keep top 50–70% by score. Stage 4 (targeted): safety filter → remove toxicity. Log rejection counts at each stage to monitor data source quality over time.
