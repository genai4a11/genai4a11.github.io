SECTION 01
('What Is Distillation?', "Distillation (Hinton 2015) trains a small student model to match the outputs of a large teacher model. For LLMs, the most practical form is behavioural cloning: generate high-quality (query, response) pairs from the teacher, then fine-tune the student on those pairs. The student learns the teacher's reasoning style without having the teacher's scale.")
SECTION 02
('Teacher Data Generation', 'Use the teacher (GPT-4o, Claude Opus) to generate responses to your task-specific queries. "\n "Key considerations: diverse query coverage, rejection sampling (keep only teacher responses that pass quality checks), "\n "and sufficient volume (10K minimum, 100K for strong results).\n\nfrom openai import OpenAI\nimport json, tqdm\n\nclient = OpenAI()\n\ndef generate_teacher_data(queries: list[str], output_file: str):\n dataset = []\n for q in tqdm.tqdm(queries):\n resp = client.chat.completions.create(\n model="gpt-4o",\n messages=[{"role": "user", "content": q}],\n temperature=0.3,\n )\n answer = resp.choices[0].message.content\n if passes_quality_check(answer): # length, format, coherence\n dataset.append({"prompt": q, "completion": answer})\n with open(output_file, "w") as f:\n for ex in dataset:\n f.write(json.dumps(ex) + "\\n")\n print(f"Saved {len(dataset)} examples")')
SECTION 03
('Training the Student', 'Fine-tune a small model (Llama 3.2 3B, Phi-3 mini) on the teacher data using standard SFT. "\n "Use LoRA for parameter efficiency. Learning rate 2e-5, 3 epochs, cosine schedule. "\n "Eval on a held-out 10% of the teacher-generated data + your golden test set.\n\nfrom trl import SFTTrainer\nfrom transformers import AutoModelForCausalLM, AutoTokenizer\nfrom peft import LoraConfig\n\nmodel = AutoModelForCausalLM.from_pretrained("meta-llama/Llama-3.2-3B-Instruct")\ntokenizer = AutoTokenizer.from_pretrained("meta-llama/Llama-3.2-3B-Instruct")\n\nlora_config = LoraConfig(r=16, lora_alpha=32, target_modules=["q_proj","v_proj"])\n\ntrainer = SFTTrainer(\n model=model,\n tokenizer=tokenizer,\n train_dataset=dataset,\n peft_config=lora_config,\n max_seq_length=2048,\n)\ntrainer.train()')
SECTION 04
('Quality vs Cost Tradeoffs', "A distilled 7B model typically reaches 85–90% of a 70B teacher's quality at 10× lower inference cost. For narrow tasks (customer support, code completion in a specific framework), distillation often reaches 95%+ because the domain is well-represented in the training data. General-purpose distillation is harder — use task-specific distillation when possible.")
SECTION 05
('Speculative Decoding Link', 'Distilled small models are excellent draft models for speculative decoding with the original large teacher. The student generates candidate tokens cheaply; the teacher verifies and accepts/rejects. This gives teacher-quality output at near-student-speed — the best of both worlds.')
SECTION 06
('Production Recipe', '1. Identify your highest-volume task (e.g. classification, extraction, summarisation). 2. Generate 50K teacher examples with diversity sampling. 3. Fine-tune a 3B–7B student model with LoRA. 4. A/B test student vs teacher on 5% of live traffic. 5. If quality delta < 5%, fully migrate to student. 6. Use teacher as fallback for low-confidence student outputs.')
