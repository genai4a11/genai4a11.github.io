Override & Escalation

Mechanisms for human operators to intervene in, override, or escalate AI agent actions in real time — the emergency stop and manual override layer of production AI systems.

Response time
<1 s (kill switch)
Override types
pause/redirect/terminate
Escalation paths
2–3 tiers

SECTION 01

Override Taxonomy

Pause: halt the agent at its next checkpoint, preserving state for later resumption. Redirect: inject a new instruction into the agent's context, changing its course. Terminate: stop the agent immediately and roll back any uncommitted side effects. Escalate: transfer the task to a human operator with full context. Each type has different urgency and recovery implications.

SECTION 02

Kill Switch Implementation

A kill switch is a globally-checked flag that any agent loop must respect. " "Implement as a Redis key checked at the start of every agent loop iteration.

import redis, time
r = redis.Redis()
def is_killed(task_id: str) -> bool:
    return r.exists(f"kill:{task_id}") or r.exists("kill:all")
def kill_task(task_id: str, reason: str):
    r.set(f"kill:{task_id}", reason, ex=3600)
    log_override("terminate", task_id, reason)
def kill_all(reason: str):
    r.set("kill:all", reason, ex=3600)
    log_override("terminate_all", "*", reason)
async def agent_loop(task_id: str, state: dict):
    while not is_done(state):
        if is_killed(task_id):
            raise AgentKilledException(f"Task {task_id} was killed")
        state = await execute_next_step(state)
        save_checkpoint(task_id, state)
SECTION 03

Mid-Session Intervention

For interactive agents (chatbots, assistants), allow operators to inject messages into the conversation stream: 'This session has been flagged for review — an agent will assist you shortly.' Use a shared message queue that both the AI and operator can write to. The operator's messages are tagged with a source field so the AI knows they came from a human.

SECTION 04

Escalation Tiers

Tier 1 (automated): rule-based triggers escalate to on-call operator within 1 minute. Triggers: cost spike, repeated failures, toxicity detected, out-of-scope task detected. Tier 2 (human review): operator reviews and decides — continue, modify, or terminate. Tier 3 (incident response): task triggers a full incident (PagerDuty, Opsgenie) for situations with potential compliance or safety implications.

SECTION 05

Override Logging

Every override must be logged with: who initiated it, when, what type of override, the reason, and the agent's state at the time. This creates an audit trail for post-mortems and for training better safety classifiers. Override events should flow to the same immutable audit log as all other AI system events.

SECTION 06

Recovery After Override

After a pause or redirect, the operator must decide whether to: resume (agent continues from checkpoint), restart with modifications (adjust task parameters), or abandon (mark task as failed and notify user). For terminated tasks, notify the user with an explanation and offer alternatives. Never silently drop a task — the user should always know what happened.
