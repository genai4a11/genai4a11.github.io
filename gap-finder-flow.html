STEP 0 Poll Telegram for Priority Replies
Calls getUpdates on the Telegram bot to retrieve any messages Deepak sent since the last run.

Each reply is handled by prefix:
add source: <url> → writes a new row to the Sources DB in Notion anything else → fuzzy-matches a node label, tags it priority_week in the registry
If Telegram is unreachable, logs the failure and continues — never aborts.
Automated
STEP 1 Load Known IDs from Notion
Fetches all pages from the Notion registry across all statuses.
Builds two sets: known_ids (Node ID values) and known_labels (lowercased Label values) — the complete "already seen" universe used for deduplication in Step 3.
Automated
STEP 2 Load Sources from Notion, then Scrape
2a — Load active sources. Fetches the Gap Finder — Sources Notion database and reads every row where Active ✓. Each row has a Name, Category, and URL (direct fetch or SEARCH: query). This is the single source of truth — add a row in Notion to add a new source, no skill editing needed.

2b — Scrape each source. Fetches or searches each active URL and extracts named concept candidates by category:
✍️ blog — post titles & named tools (last 30 days) 🔧 changelog — feature names, model names, new API capabilities 🔬 arxiv — paper titles → named technique or concept 💻 github — repo names & descriptions (LLM/agent/RAG filter) 📋 job_signal — required/preferred skill names from job postings
Currently 16 active sources across all categories. Huyen · Yan · Hamel blog posts get a +0.2 high-signal score bonus in Step 4. Failed sources are logged and skipped — never abort.
Automated
STEP 3 Fuzzy-Match vs Registry
Each extracted concept is normalised (lowercase, punctuation stripped) then compared against known_ids and known_labels using difflib.SequenceMatcher.

Score > 0.75 → already covered → skip
Score ≤ 0.75 → genuine gap → keep

Surviving candidates are deduplicated by concept name.
Automated
STEP 4 Score & Filter
Each gap concept gets a relevance score (0–1) from signal strength:
+0.30Appears in ≥ 2 different sources
+0.20Featured in a blog by Chip Huyen, Eugene Yan, or Hamel (high-signal authors)
+0.20Named in an arXiv paper title (not just abstract)
+0.20Listed as a required skill in ≥ 2 job postings
+0.10GitHub repo name with >500 stars this week
Only concepts scoring ≥ 0.30 pass through. Sorted by score descending. Capped at 15 candidates per run.

STEP 6 Send Weekly Digest to Deepak
Composes a ranked digest of all new candidates with scores, sources, and one-line descriptions. Delivers via a fallback chain:
Telegram bot → if blocked → Mac Mail (osascript) → if fails → Gmail draft → if all fail → Notion only
The digest includes a 📌 reply prompt — Deepak can reply with any concept name to flag it as priority for next week's Step 0.
